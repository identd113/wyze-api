# Release notes: wyze-api 2.0.0-beta.1

First 2.0 beta, published to npm on 2026-04-28 under the `beta` tag (`npm install wyze-api@beta`). Stable users on `latest` were not affected. The tag is `v2.0.0-beta.1` (`488b458`).

**Pairs with:** `homebridge-wyze-smart-home@2.0.0-beta.1`.

The full list of what changed is in the `v2.0.0-beta.1` section of `CHANGELOG.md`. This page is the short version for whoever ships and supports it.

## What it is

- The monolithic `index.js` was split into per-family modules under `src/devices/`, `src/services/` and `src/utils/`. The public surface (`require('wyze-api')`) is unchanged.
- HomeKit camera streaming primitives: WebRTC connection info with reconnect, RTP forwarding, snapshot capture through bundled ffmpeg, and a unified snapshot getter.
- `shared/homekit.js` holds the Wyze to HomeKit value converters; the frozen `WyzeAccessoryModels` map is the one place a model code is routed to a device class.
- New devices: Robot Vacuum (`JA_RO2`), Sprinkler Controller (`BS_WK1`), Lock Bolt V2 (`DX_LB2`) and Palm Lock (`DX_PVLOC`), the devicemgmt API for newer cameras, Light Strip Pro per-subsection colors.
- A new `WyzeLogger` replaced `@ptkdev/logger`, and the redaction and hardening code was merged into `src/util/security.js`.
- Reliability fixes: a refresh-token failure falls back to a fresh login, the token persist directory is created before the first write, and bad color input no longer throws.

## Breaking changes

- The logger was replaced (`logLevel` option; `apiLogEnabled: true` still maps to `debug`).
- Security utilities were consolidated; the public re-exports are kept.
- All base URLs moved to `constants.js`.
- Removed dependencies: `aws-sdk`, `base64-js`, `colorsys`, `crypto-js`, `moment`, `urllib`. `axios` floor is `^1.12.0`.

## Known gaps at release

- `npm audit --omit=dev` still reported 4 findings, all in the `werift` chain (`ip`, `uuid`). Fixed in beta.3 by moving to `werift` `^0.25.1`.
- Node.js was not declared in `engines`. Node 22 or newer became the requirement in beta.3.
- 178 wyze-api tests passed.
